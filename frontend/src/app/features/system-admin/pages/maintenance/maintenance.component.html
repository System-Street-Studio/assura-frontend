Database Backup

Generate a complete snapshot of the current live database. This includes all structural data, historical audit logs, user profiles, and operational information.

Note: Generating a backup may take a few moments depending on the size of the database. A .sql file will be downloaded to your computer which can be directly imported into a standard MariaDB/MySQL instance.
